16 October 2026Native app · Development build

More ways to remember. Clearer ways to practise.

Recent Android and iOS work, checked against the current source and development-build evidence.

  • New-character daily practice. A configurable daily goal, up to 20 where content and access allow, now chooses unseen eligible characters first. Scheduled reviews no longer consume the new-character allowance; the same-day set persists, legacy plans migrate without losing history, and review is a fallback once unseen eligible content is exhausted.
  • Quick test inside You. Recall learned characters before revealing the answer. Swipe left for “don’t know” and right for “know,” or use the equivalent buttons; review missed characters from the recap. The self-check leaves learning history, streak and XP unchanged.
  • Repeat today’s practice. Start additional rounds of today’s studied set. Premium skips the gate; free rounds in monetized Android development require three completed optional rewarded ads, with saved unlock progress. iOS has Premium repeat rounds; the free ad-supported unlock is not integrated there.
  • Offline reference vocabulary. 125,271 CC-CEDICT records, 32,028 Tatoeba-derived Chinese–English sentence pairs, HSK 2021 filters and 29 explicitly incomplete headword-only records. Search, alternative readings, traditional forms, exact source identities and related words are integrated into character and word inspection. Lookup does not alter lessons or learning progress.
  • Remember by picture. Meaning pictures for 131 characters and exact matches for 226 dictionary headwords, using 170 reusable artwork objects including existing originals and credited imports. Picture/character toggles, larger images and credits work across character details, daily practice and lesson inspection. Missing picture coverage stays explicit.
  • Character components. Imported breakdowns for the 3,500-character catalog, with supported spatial diagrams and source meaning/sound hints. Unsupported or missing layouts are shown as gaps; a shape diagram is distinct from a meaning picture.
  • Clearer native reading. Larger focal characters, connected left-to-right sentences, inline character inspection and clearer lesson/You layouts. Today navigation, native Back behavior and word-detail return paths were repaired and checked on Samsung.
  • Native conveniences. System sharing, app shortcuts, localized reminder controls and notification-permission handling. Android also has a daily-character widget with streak information, an animated Path, local XP and levels, answer-combo feedback, goal celebrations, a daily reward and streak sharing. Some system flows still need device verification; iOS has not had a physical-phone pass for this update.
  • Progress and navigation fixes. Today returns correctly through main tabs and warm shortcuts; Characters search is retained. Stale or duplicate recall/repeat answers are rejected, repeat unlocks are consumed once, and iOS reading position saves independently of audio.
  • Feedback and preferences. 18 bundled feedback effects, haptic controls and reorganized practice/reminder settings. Existing system/light/dark appearances remain available; dark mode is not new in this update.
  • Stories and saved reading. Two starter stories plus chapters drawn from existing lessons, optional reading help and saved progress. Expanded lessons and translations remain under language review. Returning to practice hides the answer again.

Latest Android owner preview installed and checked on a physical Samsung; 117 Android tests pass. iOS app/test targets compile and daily-queue core checks pass, but physical iPhone validation and iOS rewarded-ad integration remain outstanding. These changes are not confirmed as a new public store release. Owner preview access does not change store entitlements.
